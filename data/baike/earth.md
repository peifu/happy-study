# 地球显生宙地质历史纪年分类知识
 
 地球约46亿年的历史中，**显生宙**（距今约5.4亿年至今）是生物面貌最为丰富多彩的阶段，意为“看得见生物的年代”。显生宙分为古生代、中生代和新生代，下文按从古到今的顺序详细梳理各纪的特征。
 
 ---
 
 ## 一、古生代（距今约5.4亿—2.5亿年）
 
 古生代是“古老生命”的时代，生物从海洋走向陆地，完成了从水生到陆生的关键跨越。
 
 ### 1. 寒武纪（5.41亿—4.85亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 著名的**寒武纪生命大爆发**发生于此期，几乎所有现生动物门类的祖先在短时间内出现，复杂海洋生态系统初步形成。 |
 | **动植物** | 海洋无脊椎动物繁盛，三叶虫遍布海底；**奇虾**（体长可达2米）为顶级掠食者，拥有发达的复眼；古杯动物（一类已灭绝的海绵）构成生物礁；早期脊椎动物（如昆明鱼）已出现。 |
 | **霸主** | **奇虾**（放射齿目），寒武纪海洋的顶级捕食者。 |
 
 ### 2. 奥陶纪（4.85亿—4.43亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 海洋无脊椎动物进入全盛期，原始脊椎动物（无颌类）出现。末期发生**奥陶纪末大灭绝**（伽马射线暴假说），约60%物种灭绝。 |
 | **动植物** | 笔石繁盛，**角石**（头足纲，体长可达9米）成为海洋顶级掠食者；三叶虫仍丰富；珊瑚和腕足类大量发育。 |
 | **霸主** | **角石**，巨大鹦鹉螺类，将奇虾驱赶下王座。 |
 
 ### 3. 志留纪（4.43亿—4.19亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 生物登陆的重大转折期：**有颌鱼类首次出现**，**陆生植物（裸蕨类）首次登陆**。 |
 | **动植物** | 板足鲎（巨型海蝎子）称霸海洋；无颌类进一步发展；原始陆生植物为小型草本状，高约18-50cm。 |
 | **霸主** | **板足鲎（鲎）**，在海洋中反制角石，部分种类开始向陆地探索。 |
 
 ### 4. 泥盆纪（4.19亿—3.59亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 被称为**“鱼类时代”**。鱼类全面繁荣，**两栖动物首次登陆**（鱼石螈），最早的森林形成。末期发生大灭绝，盾皮鱼类几乎全部消亡。 |
 | **动植物** | **邓氏鱼**（盾皮鱼，体长可达8-11米，咬合力惊人）为海洋霸主；硬骨鱼和软骨鱼兴起；蕨类植物形成森林。 |
 | **霸主** | **邓氏鱼（泰雷尔邓氏鱼）**，泥盆纪海洋的终极“毁灭者”。 |
 
 ### 5. 石炭纪（3.59亿—2.99亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | **巨虫时代**：大气含氧量高达35%，催生巨型昆虫（如巨脉蜻蜓翼展近1米）。**爬行动物首次出现**（羊膜卵的演化）。末期冰期事件导致46%物种灭绝。 |
 | **动植物** | 蕨类植物形成大规模森林（现代煤炭主要来源）；两栖动物（如引螈）体型巨大；巨型蜻蜓和远古蜈蚣称霸陆地。 |
 | **霸主** | **引螈**（大型两栖动物）与**巨脉蜻蜓**、**远古蜈蚣虫**形成三足鼎立。 |
 
 ### 6. 二叠纪（2.99亿—2.52亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 盘古超大陆形成，**爬行动物全面辐射**（合弓纲，即哺乳动物祖先的支系占据主导）。末期发生**地球史上最大规模的灭绝事件**（西伯利亚暗色岩事件），约75%-90%物种消失。 |
 | **动植物** | 兽孔目（如丽齿兽）为陆地顶级掠食者；松柏类裸子植物兴起；三叶虫在此期末彻底灭绝。 |
 | **霸主** | **丽齿兽/狼蜥兽**（兽孔目爬行动物），二叠纪中晚期的陆地统治者。 |
 
 ---
 
 ## 二、中生代（距今2.52亿—0.66亿年）
 
 中生代是**爬行动物时代**，恐龙主导陆地，裸子植物繁盛。
 
 ### 7. 三叠纪（2.52亿—2.01亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 大灭绝后的复苏期，**恐龙出现**，**哺乳动物出现**。盘古大陆仍为一体，气候干燥。 |
 | **动植物** | 早期恐龙（如腔骨龙）开始崛起；大型主龙类占据生态位；松柏和苏铁类裸子植物繁盛。 |
 | **霸主** | **早期恐龙**及大型主龙类，逐渐取代合弓纲成为陆地主导。 |
 
 ### 8. 侏罗纪（2.01亿—1.45亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | **恐龙的黄金时代**，体型巨大化，种类多样化。气候温暖湿润，裸子植物森林遍布。**鸟类出现**（始祖鸟）。 |
 | **动植物** | 蜥脚类（如腕龙、梁龙）和兽脚类（如异特龙）称霸；菊石在海洋繁盛；银杏、苏铁等裸子植物占主导。 |
 | **霸主** | **各类大型恐龙**（蜥脚类、兽脚类），无可争议的全球统治者。 |
 
 ### 9. 白垩纪（1.45亿—0.66亿年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 恐龙达至极盛，**被子植物首次出现并迅速辐射**。末期发生**白垩纪末大灭绝**（小行星撞击假说），非鸟恐龙全部灭绝。 |
 | **动植物** | 暴龙、三角龙、甲龙等标志性恐龙繁盛；海洋中沧龙和蛇颈龙称霸；开花植物开始改变陆地生态面貌。 |
 | **霸主** | **暴龙（霸王龙）** 等大型兽脚类恐龙，白垩纪晚期陆地的终极掠食者。 |
 
 ---
 
 ## 三、新生代（距今6600万年前至今）
 
 新生代是**哺乳动物时代**，被子植物主导，最终人类登场。
 
 ### 10. 古近纪（6600万—2300万年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 大灭绝后生态位真空，**哺乳动物迅速辐射**，演化出众多大型种类。古近纪包括古新世、始新世、渐新世。 |
 | **动植物** | 始祖马、剑齿类（肉齿目）、早期鲸类出现；被子植物森林覆盖全球；鸟类也经历巨大辐射。 |
 | **霸主** | **大型肉食哺乳动物**（如鬣齿兽、安氏中兽）逐渐占据顶级生态位。 |
 
 ### 11. 新近纪（2300万—258万年前）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | 哺乳动物进一步演化，**草原大面积扩张**，促使食草动物和食肉动物共同进化。包括中新世和上新世。 |
 | **动植物** | 剑齿虎、猛犸象的早期祖先、三趾马等繁盛；草原生态系统成熟。 |
 | **霸主** | **大型食肉哺乳动物**（如巴博剑齿虎、犬熊）。 |
 
 ### 12. 第四纪（258万年前至今）
 
 | 项目 | 内容 |
 |------|------|
 | **特点** | **人类时代**。多次**冰期（大冰期）** 和间冰期交替，深刻影响全球生态格局。分为更新世和全新世。 |
 | **动植物** | 猛犸象、披毛犀、剑齿虎等冰期巨型动物（大多于末次冰期后灭绝）；现代动植物群形成。**人类（智人）** 在约30万年前出现，并在末次冰期后迅速扩散至全球。 |
 | **霸主** | **人类（智人）** ，凭借复杂的工具制造能力和高度发达的社会组织，成为地球历史上第一个能够系统性地改造自然环境的物种。 |
